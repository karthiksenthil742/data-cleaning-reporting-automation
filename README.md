# Automated Student Data Cleaning & Performance Reporting

An end-to-end Python-based data cleaning and reporting automation project that transforms a messy student dataset into a validated, analysis-ready dataset and automatically generates a structured Excel performance report.

## 📌 Project Overview

This project demonstrates an automated data preprocessing and reporting workflow using Python.

The workflow handles:

- Missing values
- Exact duplicate records
- Duplicate Student IDs
- Inconsistent categorical values
- Invalid numerical values
- Data quality validation
- Student performance calculations
- Automated KPI reporting
- Performance visualization
- Automated Excel report generation

The objective is to replace repetitive manual preprocessing and reporting tasks with a reusable Python workflow.
